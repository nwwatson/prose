# Social Embeds

X posts and YouTube videos embedded in rich text through oEmbed.

## Social Embeds
`XPost` and `YouTubeVideo` models with oEmbed fetching, embedded in rich text via ActionText. Both include `OembedAttachable` (`app/models/concerns/oembed_attachable.rb`), which includes `ActionText::Attachable`, derives `to_attachable_partial_path`/`to_trix_content_attachment_partial_path` from `model_name` (e.g. `"x_posts/x_post"`), and implements `find_or_create_from_url(url)`: it normalizes the URL, bails out via the overridable `valid_oembed_url?` class method (used by `YouTubeVideo` to reject URLs with no extractable video ID), then `find_or_create_by(url:)` — calling the private `assign_oembed_url_attributes` hook (overridden by `YouTubeVideo` to set `video_id` before validation) and fetching+applying oEmbed data via the per-model `oembed_endpoint`/`apply_oembed(data)` methods. `OembedFetcher.fetch(endpoint_url)` (`app/services/oembed_fetcher.rb`) is the single place that performs the blocking `Net::HTTP` oEmbed request (including the `cert_store.flags = 0` reset for system OpenSSL builds, and `OPEN_TIMEOUT` 5s / `READ_TIMEOUT` 10s, since it runs synchronously inside the admin paste request); it returns `{}` and logs a warning on any error or non-JSON response instead of raising. `paste_embed_controller.js` is the single Stimulus controller mounted on the post editor's writing area — it holds a module-level `PROVIDERS` table (regex pattern per provider) and a `data-paste-embed-urls-value` JSON object (`{ xPost:, youtube: }`, built from the admin routes in `_form.html.erb`) mapping each provider to its create endpoint; on paste it tests the clipboard text against each pattern, posts to the matching URL via `requestJSON`, and inserts the returned attachment via `admin/lib/action_text.js#insertAttachment(editor, { sgid, html })`. `lib/twitter_widgets.js#loadTwitterWidgets()` memoizes the `widgets.js` script tag/load so `x_post_widget_controller.js` — mounted once per tweet by `x_posts/_x_post.html.erb` — never appends a duplicate script tag for a post with multiple embedded tweets; the redundant wrapper-level mount on `posts/show`/`admin/posts/_preview` was removed since the per-tweet mount is sufficient.
